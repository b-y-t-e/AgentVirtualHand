How it works

  1. They open Assist

    On the computer that needs help. It shows a support code right away, nothing to set up.

  2. They send you the code

    By chat, mail or phone. A code works once: after you use it, it is gone.

  3. You paste it into Hub

    Hub pairs with that computer and gives you a prompt for your AI agent. The agent works on that one machine.

What keeps it safe

Nothing listens on the network
Both sides connect out through Tailcat.Link. The local API answers on 127.0.0.1 only.
Access ends with the window
Closing Assist cuts everyone off and stops every command that was still running.
One prompt, one computer
Each machine in Hub gets its own address and token. A prompt made for one cannot reach another.
Changes leave a trail
Commands and file changes are written to an audit log on the computer they ran on.
